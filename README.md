# BCS601-USN089

## Project Title
Basic Operations Web Application using Python

---

## Introduction
This project is a simple web-based application developed using Python and Flask.  
It demonstrates basic programming concepts by performing operations such as HCF, LCM, string reversal, and factorial calculation.  

The application is deployed on a cloud platform so that it can be accessed through a web browser.

---

## Objectives
- To understand basic programming logic  
- To implement mathematical operations using Python  
- To convert a console program into a web application  
- To learn GitHub for version control  
- To deploy an application on a cloud platform  

---

## Features
- HCF calculation using Euclidean algorithm  
- LCM calculation based on HCF  
- String reversal  
- Factorial generation from 4 to 8  
- Web interface using Flask  
- Cloud deployment using Render  

---

## Technologies Used
- Python  
- Flask  
- HTML  
- GitHub  
- Render  

---

## Program Description
The application performs the following operations:

1. Takes two numbers and calculates HCF step-by-step  
2. Uses HCF to calculate LCM  
3. Accepts a string and reverses it  
4. Displays factorial values from 4 to 8
